# Archived console and recorded playback

The pre-simplification console is preserved here, including `replay()` and
`replayFrame()` in legacy-console.js. It is not loaded or linked by the console.
To reuse it for a portfolio demo, pair the archived HTML/JS/CSS (renamed to their
original index.html/app.js/style.css filenames) with the current packet-codec.js,
mark.svg, link-view.js and an exported data.json containing release.mission.
Recorded mission files remain under docs/verification/m5-demo. Scenario runners
and shared codec vectors remain unchanged as test/CLI tools.
